# Otto app

The second screen and the device agent in one Android app, in Kotlin:

- a handle on the screen's edge that fades the second screen in and out over any app;
- the browser agents drive (embedded Chromium, in its own process), files, artifacts, terminal, desktop;
- links to the box and the hub, from any app, open here;
- the device agent: accessibility-based UI tree and input, screenshots, installs, logs, served to the box as an HTTP API through the tunnel the app keeps open.

Moving in from second-screen and device-agent, rewritten from Java to Kotlin on the way.
